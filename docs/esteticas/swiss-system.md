# Swiss System

## Identity

Swiss System is a contemporary digital interpretation of the
International Typographic Style, commonly known as Swiss Style.

The aesthetic explores the idea that:

> information itself can become the visual object.

The microsite should feel like a living graphic design system:
precise, structured, typographic, confident, and highly intentional.

This is not a historical museum recreation of Swiss graphic design.

It should take the principles of Swiss modernism and reinterpret them
for a contemporary interactive website.

The website itself should feel like a designed visual system.

---

# Conceptual qualities

The experience should feel:

* rational
* precise
* confident
* editorial
* systematic
* intelligent
* contemporary
* highly structured
* visually disciplined
* surprisingly dynamic

The central tension should be:

* order / movement
* system / expression
* information / image
* grid / disruption
* precision / scale

---

# Visual direction

The aesthetic should be substantially different from:

* Root Tecnologías
* Terminal Bloom
* Nocturne Grid

Do not reuse their visual language.

The primary visual territory should draw from Swiss and International
Typographic Style principles:

* strong modular grid
* asymmetric composition
* sans-serif typography
* generous negative space
* strong alignment
* large numerical indexes
* thin rules
* photographic crops
* restrained color
* typographic hierarchy
* mathematical relationships
* visual rhythm

Use a predominantly light interface.

A suitable palette could be:

* white or warm white
* black or very dark charcoal
* one strong accent color

Red is historically associated with Swiss graphic design, but it is
not mandatory. Choose one accent color and use it deliberately.

Do not use many accent colors.

Do not use gradients as a defining visual element.

Do not use glassmorphism.

Do not use rounded cards as the primary layout system.

---

# Typography

Typography must be one of the strongest elements of the experience.

Use a contemporary sans-serif / grotesk as the primary typeface.

Possible characteristics:

* clean geometric or neo-grotesk forms
* strong weights
* highly controlled line-height
* clear hierarchy
* large numerical characters

A monospace font may be used very sparingly for technical metadata,
but it should not become the dominant typeface.

Do not use serif typography as a primary visual element.

Typography should behave like architecture.

Large type may occupy several grid columns.

Small text may function as annotations.

Numbers should be treated as compositional elements rather than
ordinary labels.

Avoid making every heading enormous.

---

# Grid philosophy

The grid is the fundamental visual system.

Build a real responsive layout grid rather than simply decorating the
page with grid lines.

The desktop composition should use a clear modular structure with
consistent columns, gutters, margins, and alignment.

Elements should visibly relate to the grid.

Some elements may intentionally break or cross the grid, but those
exceptions should feel deliberate.

Use:

* columns
* rows
* intersections
* alignment axes
* numbered positions
* vertical rules
* horizontal rules
* whitespace

The grid should remain conceptually present on smaller screens.

---

# Responsive grid requirement

Responsive behavior is a core part of this aesthetic.

Do NOT simply scale the desktop design down.

The layout must be intentionally redesigned for:

* large desktop
* standard desktop
* tablet
* small mobile
* very small mobile

The grid should progressively transform.

For example:

Desktop:

* 12-column or similarly structured grid

Tablet:

* reduced column count
* adjusted gutters
* simplified compositions

Mobile:

* compact 4-column or similarly appropriate grid
* carefully reorganized content
* preserved alignment relationships
* simplified decorative rules where necessary

The exact numbers are implementation decisions.

The important requirement is that the mobile version should still
look like Swiss System, not like a generic stacked mobile page.

Never allow horizontal page overflow.

Do not rely on tiny text to preserve desktop compositions.

Images must resize and crop intentionally.

Large typography must scale using appropriate responsive sizing.

Interactive elements must remain comfortably tappable.

# Required website structure

Build a complete one-page landing page.

The exact composition is flexible, but the page must feel like a
complete visual system rather than a collection of generic sections.

Include at minimum:

1. Opening / Index
2. Grid system
3. Visual studies
4. Typography + image composition
5. Proportion / measurement
6. Interactive variables
7. Closing composition

---

# Navigation

Create a minimal navigation system appropriate to Swiss System.

It should not resemble the Root Tecnologías navigation.

Possible elements:

* SYSTEM / 04
* INDEX
* STUDIES
* GRID
* TYPE
* VARIABLES

The navigation should be compact and typographically disciplined.

Include:

`← BACK TO AESTHETIC`

It must navigate to:

`/esteticas/swiss-system`

Use the same browser tab.

The return action should visually belong to Swiss System.

---

# Opening / Index

The first viewport should immediately establish the aesthetic.

Avoid a conventional agency hero.

Create a strong typographic composition using:

* system identifier
* large title
* index number
* small metadata
* grid structure
* one carefully positioned image or graphic element

The opening should feel like entering a visual system.

Possible conceptual language:

`SYSTEM / 04`

`ORDER / FORM / SCALE`

`VISUAL RESEARCH`

These are examples of tone rather than mandatory copy.

Do not use generic marketing phrases such as:

"Transform your business"

"Creative digital solutions"

"Welcome to our website"

---

# Grid section

Create a substantial section demonstrating the underlying grid.

The visitor should be able to understand that the visual system is
constructed rather than arbitrary.

Show relationships between:

* columns
* margins
* typography
* image
* numerical information

Consider allowing selected grid elements to react subtly to hover,
focus, or pointer movement.

The interaction should reveal the system rather than decorate it.

---

# Visual studies

Create several fictional visual studies.

Do NOT present them as a conventional card grid.

Instead, each study should occupy a different composition within the
overall grid.

Possible studies:

* FORM
* RHYTHM
* SCALE
* CONTRAST

Each study should have:

* number
* title
* short description
* metadata
* visual composition

Make each study visually distinct while preserving the same design
system.

Some studies may be primarily typographic.

Others may emphasize photography.

Others may emphasize geometry or numerical relationships.

The page should demonstrate that one grid can produce different
compositions.

---

# Typography / Image section

Create a section where typography and imagery interact directly.

Avoid the conventional pattern of:

image on one side + text on the other.

Instead, allow typography to overlap, frame, crop, align with, or
visually interrupt the image.

Use carefully selected architectural, urban, industrial, human, or
abstract imagery if imagery is appropriate.

Avoid recognizable commercial stock-photo aesthetics.

Images should feel like graphic-design material.

The composition must remain readable and accessible.

---

# Proportion / Measurement

Create a section exploring scale and proportion.

Use fictional measurements and visual relationships.

Examples:

* 04 columns
* 12 modules
* 72 px
* 03 studies
* 01 system
* 8:5 ratio

These should function as visual information, not merely statistics.

Large numbers can become major graphic elements.

Do not turn this into a conventional statistics row.

---

# Interactive variables

Create one meaningful interactive area where the visitor can alter
or explore the visual system.

Possible interactions:

* changing grid density
* changing typographic scale
* switching between compositions
* activating/deactivating structural lines
* changing image crop
* moving through different system states

The exact interaction is flexible.

It should demonstrate the relationship between rules and visual
expression.

Provide accessible controls.

The experience must remain usable without pointer interaction.

---

# Motion

Motion should be restrained and purposeful.

Possible uses:

* grid lines appearing progressively
* typography shifting between grid positions
* image cropping changing subtly
* numerical indexes updating
* transitions between visual studies
* controlled layout transformations

Do not animate every element.

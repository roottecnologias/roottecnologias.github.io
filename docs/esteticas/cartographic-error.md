# Cartographic Error

## Concept

Cartographic Error is an experimental cartographic environment documenting a geography that should not exist.

The visitor enters what initially appears to be a precise mapping and surveying system.

As they explore it, inconsistencies begin to appear:

* distances don't behave correctly
* roads intersect impossible terrain
* coordinates contradict one another
* elevations form impossible structures
* locations appear where they shouldn't
* borders overlap
* routes return to unexpected places
* different map layers disagree

The central concept is:

> **A perfectly precise map of an impossible place.**

The experience should feel like an encounter with a mysterious scientific/cartographic artifact.

It is not a normal website containing maps.

**The map itself IS the interface.**

# Critical Visual Independence

This aesthetic must be treated as a completely independent visual world.

Do NOT reuse visual components from the Root portfolio except where technically necessary for routing/application infrastructure.

The following must NOT be inherited from the main portfolio:

* Root navigation
* breadcrumbs
* section navigation
* Root typography
* Root buttons
* Root cards
* Root spacing system
* Root border styles
* Root colors
* Root CSS variables
* Root hero patterns
* Root layout primitives
* Root labels
* Root badges
* Root UI conventions

In particular:

### No breadcrumbs

Do not include breadcrumb trails such as:

`Home / Estéticas / Cartographic Error`

or any equivalent.

The only external navigation should be a subtle:

`← BACK TO AESTHETIC`

The map should provide the internal navigation.

### Typography is part of the aesthetic

Do NOT automatically inherit the typography used by the Root portfolio.

Choose typography specifically for Cartographic Error.

Use a combination such as:

* technical cartographic sans-serif
* condensed utility typography
* small monospaced coordinate metadata
* distinctive display typography for geographic names

Typography should resemble a sophisticated surveying/cartographic system rather than a modern agency website.

The aesthetic should be able to change its entire typographic system without affecting Root.

# Quality Bar

This aesthetic must be treated as a **high-quality interactive design piece**, not a collection of decorative map elements.

Avoid the feeling of:

* a template
* a dashboard
* a SaaS mapping application
* a generic portfolio page
* a Google Maps clone
* a random SVG map
* decorative topographic lines behind normal content

Every visual element should have a compositional or informational purpose.

The result should feel art-directed, deliberate, sophisticated and finished.

Prioritize:

* excellent typography
* precise alignment
* coherent cartographic hierarchy
* sophisticated color relationships
* carefully designed interactions
* believable map conventions
* meaningful micro-details
* responsive composition
* polished transitions
* visual restraint

# Visual Direction

## Overall Character

The visual language should feel like:

**scientific cartography + fictional geography + editorial design + experimental interface**

Possible references in spirit:

* topographic maps
* nautical charts
* geological surveys
* astronomical maps
* military surveying documents
* transit diagrams
* expedition maps
* technical atlases

Do not literally copy any existing map system.

Create a fictional cartographic language.

---

# Color

Use a restrained cartographic palette.

Possible foundation:

* warm paper
* pale mineral gray
* muted sand
* dark ink
* desaturated green
* muted blue
* restrained red/orange for anomalies

Avoid the typical bright "Google Maps" palette.

Color should communicate information.

For example:

* blue → water
* green → vegetation/elevation
* red → anomaly
* dark ink → infrastructure
* muted orange → surveyed boundary

But the exact palette should be art-directed.

---

# Typography

Typography should be completely independent from Root.

Consider:

### Primary

A refined technical grotesk or humanist sans-serif.

### Secondary

Monospace for:

* coordinates
* elevations
* measurements
* survey IDs
* timestamps

### Display

A distinctive condensed or editorial face for major geographic names.

Use typography as part of the map itself.

For example:

A mountain name can follow a contour.

A region name can span several map columns.

Coordinates can sit at precise geographic locations.

Large labels can overlap the map intentionally.

---

# The Map Is the Interface

The central visual system should be a large fictional map.

The user should be able to:

* pan
* zoom
* inspect locations
* toggle layers
* select coordinates
* measure distances
* trace routes
* discover anomalies

Do not hide the map inside a small card.

The map should occupy substantial portions of the viewport.

---

# 01 — ORIENTATION

The opening should immediately present the fictional geography.

Do not create a conventional hero.

Instead:

* show the map
* establish geographic scale
* reveal a few major landmarks
* introduce coordinates
* provide minimal orientation information

Possible title:

`CARTOGRAPHIC ERROR`

But it should exist **inside the cartographic composition**, not above a generic hero section.

The opening should feel like unfolding an enormous map.

---

# 02 — THE MAP

Create the main interactive cartographic environment.

The map should contain:

* terrain
* contour lines
* bodies of water
* roads/trails
* settlements
* borders
* coordinate system
* elevation information
* survey markers
* geographic labels
* anomalies

The geography should feel internally coherent.

Avoid random generated squiggles.

Create a believable visual hierarchy.

---

# 03 — MAP LAYERS

Provide interactive layer controls.

Possible layers:

* TERRAIN
* ELEVATION
* WATER
* ROADS
* SETTLEMENTS
* BORDERS
* SURVEY
* ANOMALIES

Turning layers on/off must produce meaningful visual changes.

Do not present the controls as generic UI cards.

They should resemble cartographic controls.

---

# 04 — IMPOSSIBLE GEOGRAPHY

Gradually reveal geographic contradictions.

Examples:

### Recursive road

A road appears to return to its own starting point despite covering a non-zero distance.

### Impossible elevation

A contour line intersects itself in a physically impossible way.

### Moving settlement

A settlement's recorded coordinates differ between historical surveys.

### Broken border

Two administrative boundaries occupy the same geographic space.

### Vanishing lake

A body of water exists on one layer but not another.

### Coordinate contradiction

Two different locations share the same coordinate.

These anomalies should be discoverable rather than immediately explained.
